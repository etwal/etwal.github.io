Calculator & Alarm Clock

AssemblyVHDLDE1-SoC

For this project, I used Assembly programming on the De1-Soc board to create the Calculator and VHDL using the Quartus software to create the Alarm clock.

Calculator

First I use the switches to input the number that represents the mathematical operation and I confirm by pushing Key 1 (for example for addition I input 1 using the switch keys then I press key 1 and after that, I can do the operation). For this project I used the math32 library and created my own functions for the modulo, hex, and integer square root operations.

In the video, I do the following operations:

  • 30 + 501 and it returns 531
  • 2 - 62 = 60
  • 2 * 605 = 1210
  • 840 / 4 = 210
  • 910 % 3 = 1 (modulo)
  • 432 convert to hex = 1b0
  • isqrt(65) = 8 and isqrt(899974) = 948

Clock/Alarm

In this video, at first, I set the time by inputting the numbers in binary using the switch keys on the left and then pushing the keys on the right (Key 1 saves the input for hours, Key 2 pushes the input for minutes, Key 3 pushes the input for seconds, and Key 4 pushes the whole number to the display). The light on the far left indicates AM when on and PM when off. I then set an alarm to 12:05 by inputting the number using the switch keys to save it and it is indicated that it goes off at 12:05 by the LED on the left turning on.
