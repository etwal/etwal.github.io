SIFT Image Recognition with GUI

SIFTOpenCVPyQt

For this project, I used PyQt to create the GUI for my image recognition program and I implemented a Homography based tracker using SIFT.

PyQt GUI:

This program would be given an input image and then it draws a rectangle around it when that image is found in the live stream from the device's camera (or another type of image input).

For the code, I used the detect and compute function from SIFT documentation to find key points and descriptors for the given image and the images captured by the device's camera. I would then find the best two matches and create two arrays one for each image’s key points. Then using the findHomography function I find the transformation matrix and show the video with a rectangle around the detected input image we are looking for.

This is the GitHub page for my project: https://github.com/etwal/ENPH353_Lab4
